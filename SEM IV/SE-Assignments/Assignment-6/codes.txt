3. CPS 3:


@startuml
[*] --> Login

Login : Junior Engineer logs into the CPS system
Login --> Dashboard

Dashboard --> BugTracker
BugTracker : Opens bug/task report

BugTracker --> AnalyzeError
AnalyzeError : Reads logs, traces error

AnalyzeError --> TryFix

state TryFix {
  [*] --> ApplyFix
  ApplyFix --> RunCode : Fix applied
  RunCode --> CheckOutput

  CheckOutput --> Success : Output correct
  CheckOutput --> ApplyFix : Still error

  Success --> [*]
}

TryFix --> DocumentFix
DocumentFix : Notes the issue and how it was solved

DocumentFix --> CommitFix
CommitFix : Commits and pushes the fix

CommitFix --> Dashboard
Dashboard --> Logout
Logout : User logs out
Logout --> [*]
@enduml
